# PCBA 物料需求与采购计划

本地单用户 Web 应用。Python 3.12。

```bash
cd /workspace/-
python -m pip install -r requirements.txt
python -m uvicorn app.main:app --host 0.0.0.0 --port 8000
```

浏览器访问部署机器的 8000 端口。云平台需自行配置端口访问；本地启动可访问 localhost:8000。

BOM 无需上传，默认扫描仓库当前目录第一层 XLS/XLSX。可设置 `BOM_DIRECTORY` 为其他绝对目录；多版本文件可命名为 `PCBA编码__REV002.xlsx`。目录中原始 Excel 不会修改。

点击“载入仓库样例”→“计算物料需求”可体验两个 PCBA、12 种物料、自动补充6条库存。上传接口支持订单和含“库存”文件名的库存表，按表头识别。多版本 BOM 需明确选择。

支持人工调整发料、选择采购口径、隔离库存模拟、SQLite 批次历史、九表 Excel（公式和缓存结果）、下载补充库存。保存调整会新建批次。数据及原文件快照存 `.local/`，可用 `PCBA_DATA_DIRECTORY` 指定目录；备份时备份整个目录。

验证：`python -m unittest discover -s tests -v`。

## 第一版限制

仅用于受限本地/内网单用户试用，没有登录权限，不应直接暴露公网。SQLite 替代设计中的 PostgreSQL。校验采用整批阻断，暂不支持部分范围采购。没有真实库存扣账和自动外发采购。暂未实现采购参考文件导入、手动表头映射、当前有效 BOM 的管理页面、供应商编辑和版本差异比较；供应商未知留空。导出统一 XLSX，不保证原工作簿样式；本机库存需用户下载后替换。

Excel/WPS 打开后公式交互重算仍需人工验收；自动测试校验公式和缓存。采购口径每次生成时明确选择，不自动推断。模拟发料和生产需求是两个扣减项，避免重复录入。

## 本次格式改动

导出工作簿已按《物料需求与采购计划表单格式要求》调整：BOM 明细首列为“客户物料编码”；发料记录和采购订单在物料编号后增加“规格/型号”“封装”；采购供应商从库存快照的供应商字段带入。长文本字段宽度 30、左对齐，其余字段宽度 10、居中。

点击“生成采购订单并保存”会同时生成 `库存表-YYYYMMDD.xlsx`，库存数量写入本批次理论结存：库存 + 最终发料 - 损耗后需求。同日同名文件覆盖，旧文件先备份到 `.local`；应用界面提供下载。原始库存文件仍不被修改，历史批次仍可下载自己的日期库存表。

## 最新表单规则（-02）

所有应用生成的表单统一使用：客户物料编码 16、物料编号 19、规格型号 36、BOM版本 12、采购数量 15、单机用量 15、损耗后需求 16、封装/供应商/来源 30、其他字段 12 个字符。客户物料编码、物料编号、规格型号、封装、供应商、来源左对齐，其他字段居中。

采购订单按供应商拆分：同一供应商生成一张独立的“采购订单-供应商”工作表及采购订单编号；不同供应商不会混在一张采购订单表中。

## 最新库存规则

自动创建库存表的字段顺序为：物料编号、规格型号、封装、库存、最小采购单位、供应商。导出列宽会根据当前内容自动扩展，并以配置宽度为下限，最长限制为 60；字段对齐仍按规则执行。

导入解析按关键表头名称工作，不依赖列顺序或固定列数；多余字段会保留在源文件但不参与计算，缺少非关键字段时使用空值。订单、库存和 BOM 的关键字段缺失会给出明确错误。

## 最新列宽规则

所有生成工作表的每列宽度为该列字段名和数据内容中最长文本长度的较大值，再增加 3 个字符宽度；因此数字和长文本不会因固定宽度不足显示为 `####`。订单汇总中的 `PCBA` 列名为 `客户物料编码`。选择文件会自动读取，点击“重新读取”会重新读取当前已选择的同名文件。

## Windows 桌面版

应用名称：`物料需求需采购计划系统`。项目包含 `desktop.py`、`requirements-desktop.txt` 和 `build-windows.bat`。在 Windows 电脑上双击 `build-windows.bat`，会安装桌面依赖并生成：

```text
dist\\物料需求需采购计划系统\\物料需求需采购计划系统.exe
```

这是无控制台窗口的桌面程序，使用默认图标。首次构建需要联网下载依赖；之后可将整个 `dist\\物料需求需采购计划系统` 文件夹复制到其他 Windows 电脑运行。应用数据保存在该目录下的 `.local`，BOM 默认从程序目录扫描；可通过 `BOM_DIRECTORY` 环境变量指定目录。当前云环境为 Linux，不能直接产出 Windows EXE，必须在 Windows 上运行构建脚本。
